# ScratcHA

Control your home from Scratch projects, safely.

ScratcHA adds **Home** blocks to TurboWarp, so kids can make projects that read sensors and switch lights. Everything runs on your Home Assistant: the editor, the blocks and a player for saved projects.

- Nothing is allowed until a grown-up lists it.
- Deny lists, a PIN for risky things, read-only mode and rate limits.
- Works in the Home Assistant sidebar (also for non-admin users) and on your home network.

See the Documentation tab for setup.
